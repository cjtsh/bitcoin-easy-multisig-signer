Privacy notice

Publisher: Bitseeker LLC. This notice describes the project website and desktop app. It does not control the privacy practices of independent services the app contacts.

The app runs locally without a Bitseeker LLC account. It does not send seed words or private keys to the project. Public wallet addresses and transaction identifiers are sent to the explorer services selected in the app.

Website and downloads

The project website is hosted by GitHub Pages, and source code and release downloads are hosted by GitHub. Bitseeker LLC does not operate a project user account system, collect wallet data through the website, or use project-run analytics on the site. GitHub may process connection and download information under its own privacy terms. Do not submit wallet files, addresses, transaction data, device details, or secrets in GitHub issues or discussions.

Desktop app and network requests

The app reads BSMS wallet files locally and derives public addresses locally. It contacts an Esplora server for wallet address and transaction information. A server may associate those queries with your IP address.

  • Default mainnet lookups and broadcasts use mempool.space; selected mainnet outpoints are also checked through blockstream.info.
  • Fee estimates and the approximate BTC/USD reference use mempool.space.
  • Testnet4 uses the mempool.space Testnet4 service; Mutinynet uses mutinynet.com.
  • Advanced settings can select another Esplora server. Requests then go to the configured service; the app does not silently switch servers.

When you broadcast, the selected broadcaster receives the signed transaction. If accepted by the Bitcoin network, it becomes public. Hardware communication is local over supported interfaces; hardware vendors' software and services are outside this project's control.

Files and diagnostics

An optional diagnostic report is created only when you request it, saved in Downloads, and not automatically sent to Bitseeker LLC. It contains the app version, selected network, timestamps, fixed event codes, and a validated device class. Review it before sharing. A PSBT is also saved locally only when you explicitly request one. Treat wallet files, addresses, PSBTs, and signed transactions as sensitive information.

Third-party services and updates

GitHub, public explorers, and hardware vendors have their own terms and privacy practices. Review those policies before use. This notice describes the current source; older downloaded app versions may differ. Consult the documentation for the version you use.
