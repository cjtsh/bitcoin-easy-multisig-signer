Multisig for the people you trust.

Bitcoin Easy Signer is built for families and the trusted helpers they may rely on: a spouse, trustee, lawyer, or accountant. It aims to make spending from an existing multisig wallet clear enough to follow, even if you didn’t set it up.

Why I built it

Self-custody only works if someone you trust can help.

When I moved to multisig, I expected different wallet apps and hardware keys to work together. In practice, support was fragmented, setup was difficult, and even wallet-definition files could differ. I got my own wallet working. Then I asked the harder question: could my wife—or a trustee, lawyer, or accountant—use it if I couldn’t help?

News that a firmware flaw had weakened seed generation in some earlier Coldcard versions made that question feel urgent to me. The devices themselves had not been hacked; a software defect affected how some seeds were generated. It shook my confidence in relying on any single device or maker, and pushed me toward multisig with keys from different manufacturers. Coinkite’s account of the incident ↗

Bitcoin Easy Signer is my attempt to make the spending side of multisig easier for the people families may depend on. It works from one public wallet-definition file and guides a helper through review and hardware approvals—without asking the app user to enter seed words or private keys.

01

Open the wallet file

Choose the single BSMS wallet definition provided by the wallet owner. The wallet’s own signing policy determines how many keys must approve.

02

Review the payment

Check the destination, amount, network, fee, and any change before asking a hardware device to approve.

03

Approve on the devices

Connect compatible hardware keys, confirm the payment on each device, then review the finished transaction in the app.

A test bench, not the front door

Practice networks live behind developer mode.

The app opens on Bitcoin. The person it is written for—a spouse, an executor, an accountant—never needs Mutinynet or Testnet4, and picking the wrong network is a real way to lose money. So the two practice networks sit behind one button on the opening screen: Enter Developer Mode. It tells you plainly that you are leaving live Bitcoin and, once you confirm, switches to Mutinynet—the default practice network, chosen because a default has to exist and its blocks come quickly. Testnet4 stays available for a wallet that already holds Testnet4 coins.

If you are a developer, this is a good bench. Point the app at a practice wallet file and walk the whole path—import, scan, build, sign on real hardware, review, broadcast—against coins that cost nothing. It is easy to use this way, and a practice run is the right way to learn the interface before a real wallet is involved. You will need your own practice wallet file and your own practice coins; the app provides neither. To be clear about priorities: practice networks are not what this app is for. It exists to move real Bitcoin out of an existing wallet.

The choice lasts for the session only. The app writes it to no settings file, so reopening always returns to live Bitcoin, and the frame around the window and the network badge always name the network actually in force—orange for real Bitcoin, green for practice coins. Developer mode arrived in the 0.6.1 build, which is still part of the current 0.6.2 download; in the older 0.5.1 build the three network cards still sat on the opening screen. Inside developer mode the choice is Mutinynet or Testnet4—live Bitcoin is what the "Return to Bitcoin" button goes back to, not a card in that panel.

For families and trusted helpers

Make a recovery plan a person can actually follow.

Bitcoin Easy Signer is free because I want it to be useful to the Bitcoin community. It does not create wallets or keys. It helps someone spend from an existing wallet using its BSMS definition and compatible hardware signers. The goal is to make the process approachable for a loved one, trustee, lawyer, accountant, or other helper—not only the person who built the wallet.

✓

Up to three physical keys. The wallet file defines the threshold. Supported hardware depends on the app’s bundled HWI library; not every device is supported.

✓

Hardware signing. Signing happens on the hardware wallets; the app never asks for seed words or private keys.

✓

Practice networks. Testnet4 and Mutinynet are available for practice, reached through developer mode. Their coins are not real Bitcoin and do not transfer to mainnet.

!

Real Bitcoin can now be sent. Mainnet broadcast is available, behind a per-transaction confirmation on the final screen. No warranty is offered or implied. Verify every payment yourself, and never risk more than you can afford to lose.
