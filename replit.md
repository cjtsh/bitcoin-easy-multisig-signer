# Agent entry point

Read [`CURRENT-STATUS.md`](CURRENT-STATUS.md), `AGENTS.md` and `PHASE-HANDOFF.md` first, then [`RELEASE-HISTORY.md`](RELEASE-HISTORY.md), then source and tests. The current release is **0.4.13**. `PROJECT-HISTORY.md`, the earlier phase detail in `ROADMAP.md`, and `SECURITY-REVIEW-0.2.0.md` are archives. The app's user is a nontechnical spouse or estate professional; keep descriptor complexity in automatic checks, not on the main screen.

One engine serves Testnet4, Mutinynet and mainnet. The app reads an existing BSMS wallet, scans via Esplora, builds a PSBT, asks HWI hardware signers to sign, verifies the returned signatures and final transaction, and broadcasts only to the practice networks, Testnet4 and Mutinynet. Mainnet broadcast is refused in code. It never creates wallets or requests seeds/PINs. Receive-only exports are Send All only because they do not establish change ownership.

0.2.0 was the hot-audit-fix milestone, but it broke hardware signing; do not use it for signing. The current published version is 0.4.13. Check `CURRENT-STATUS.md`, `PHASE-HANDOFF.md`, and `RELEASE-HISTORY.md` for current status and evidence. Use a patch bump for a correction to a published build. Do not claim physical-device acceptance from automated tests alone; it requires a recorded physical walkthrough. The Mac workflow is manual dispatch only, with hash-locked dependencies and a required libusb digest. Published Mac releases use Developer ID signing and notarization; unsigned test artifacts are explicitly labelled. Do not republish an existing version or put wallet material in source, diagnostics or CI.
