# Reporting a security issue

Bitcoin Easy Signer is maintained by Bitseeker LLC. Please report a suspected
security vulnerability privately using GitHub's
[private vulnerability reporting form](https://github.com/cjtsh/bitcoin-easy-multisig-signer/security/advisories/new)
when it is available. Do not include wallet files, seed words, private keys,
xpubs, addresses, PSBTs, signed transactions, device paths, or personal data in
a report.

If GitHub's private reporting form is unavailable, contact Bitseeker LLC through
the [company contact form](https://bitseeker.llc/#contact) and ask for a private
channel before sharing technical details. Do not put sensitive technical details
or wallet information in the general contact form. Once a private channel is
available, include the affected version or commit, the conditions needed to
reproduce the issue, and its likely impact. The project cannot promise a
response time, a fix, or that every report will result in a code change. Do not
use real funds to demonstrate a vulnerability.
