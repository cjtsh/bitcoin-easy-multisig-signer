# Linux v0.6.4 owner acceptance

**Reported 2026-10-05.** The owner tested the Linux AppImage and completed a
transaction, reporting that the implementation worked very well. During this
walkthrough, hardware discovery and signing felt nearly instantaneous and much
faster than on the owner's Windows and Mac systems. This is a qualitative,
owner-reported comparison, not a measured benchmark.

The owner also identified a first-launch instruction that should be explicit:
on Ubuntu or another Linux desktop, mark the downloaded AppImage executable
(in Ubuntu Files: right-click → Properties → Permissions → **Allow executing
file as program**), then double-click it and choose **Run** if prompted.

The network, transaction details, device models, release asset hash and
transaction identifiers were not supplied. No wallet or transaction material
is recorded here. This report establishes the owner's acceptance of a Linux
transaction walkthrough; it does not independently verify a published binary
or establish compatibility with every Linux distribution or device.
