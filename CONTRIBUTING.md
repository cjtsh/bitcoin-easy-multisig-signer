# Contributing

Bitcoin Easy Signer is maintained by Bitseeker LLC and distributed under the
MIT License. Before opening a pull request, make sure you have the right to
submit the contribution and to license it under the MIT License. By submitting
a contribution for inclusion, you agree that it may be distributed under the
project's MIT License. You retain ownership of your contribution; this is not
an assignment of copyright to Bitseeker LLC.

Do not submit wallet data, credentials, device identifiers, personal
information, or real transaction artifacts. Report suspected security issues
privately as described in [SECURITY.md](SECURITY.md), rather than opening a
public issue with exploit details.

Contributions are reviewed before acceptance. A submitted pull request is not
a promise that it will be merged, supported, or maintained.
