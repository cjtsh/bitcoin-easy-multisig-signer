# Contributing

Bitcoin Easy Signer is maintained by **Bitseeker LLC**, which is the sole contributor to
this repository and the only party with write access to it. The project is distributed under
the MIT License and its source is public so that anyone can read it, fork it, build it,
verify it, and share it.

**Bitseeker LLC does not accept outside contributions to the release line.** Pull requests
are not invited, and an unsolicited pull request will be closed without review. This is a
policy about the release line, not a judgment of the contribution: the line is
single-maintainer, signed, and reproduced only from `main`, so every byte in a release must
be traceable to a maintainer who stands behind the software's own safety claims.

Forks are welcome and are not contributions. A fork is your own copy under your own account;
it cannot publish under this project's identity, and questions or issues about a fork belong
with the fork.

Do not submit wallet data, credentials, device identifiers, personal information, or real
transaction artifacts. Report suspected security issues privately as described in
[SECURITY.md](SECURITY.md), rather than opening a public issue with exploit details.
